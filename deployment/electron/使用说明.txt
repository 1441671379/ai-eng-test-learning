English Learning · Windows 桌面版

从开始菜单或桌面打开 English Learning。首次启动加载本地语音模型可能需要几分钟。
无需另装 Python、Node.js 或开发工具。支持 Windows 10 2004 及更新版本的 x64 系统、Windows 11 x64。
建议使用兼容的 NVIDIA 显卡及驱动；CPU 模式会较慢，最低硬件要求仍待验证。

首次进入 设置 → 模型设置，填写自己的服务地址、模型名称和 API Key。
材料生成、写作批改和 AI 对话需要联网使用外部模型，费用由所选服务商收取。
语音识别、发音评分与 Kokoro 合成在本机运行；预置 Heart、Puck、Emma、George 四种音色。
使用口语练习时，请在 Windows 隐私设置中允许桌面应用使用麦克风。

公开版带五本词书和离线公共词典；不附个人 Anki 词书及完整知识库课程包。
知识库显示资料未安装时，请参阅项目资源准备说明；这不是启动故障。
发音与写作分数仅供学习参考，非官方考试成绩。

数据与设置：%APPDATA%\EnglishLearningDesktop
更新或卸载应用会保留该目录；不要将含个人数据和密钥的目录发给他人。
关闭应用会停止它启动的后台服务。

此测试版尚未数字签名。请只从项目官方 GitHub Releases 下载，并核对 SHA256SUMS.txt。
安装文件和已安装应用都包含多个文件，请保留完整目录。
